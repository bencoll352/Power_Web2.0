# Professional service pages and dashboard design

Scope: Powerweb3.0 marketing website, dedicated service pages and interactive dashboard demonstrations. No service application source or runtime was changed. No production customer data is loaded by the previews.

## Supplied dashboard reference

Reviewed akveo/ngx-admin `master`: README, MIT LICENSE and `src/app/@theme/styles/themes.scss`. The layout file lookup returned no content and is not treated as inspected source. The corporate theme's 2.25rem layout spacing and 1.875rem card spacing inform the CSS tokens in `dist/professional.css`. Sidebar navigation, header, work cards and muted corporate surfaces are independently implemented in static HTML/CSS/JS and adapted to the Power-Up gold/charcoal identity. Angular and Nebular are not runtime dependencies of this static marketing website. MIT notice is distributed at `dist/assets/licenses/ngx-admin.txt`.

All dashboard figures, accounts, queue entries and activity are illustrative. Tabs, keyboard navigation, search and status filtering operate locally. Nothing sends messages, starts workflows or modifies app records. Website offer copy describes configuration scope; each customer proposal must agree included services and connections.

## Source guide

`professional-site.mjs` supplies the directory, dedicated service pages and shared dashboard HTML. `dist/professional.css` provides the consistent visual system. `dist/dashboard-preview.js` implements local preview interactions. `build.mjs` integrates these with retained recruitment, coaching, partnership and other page content. Existing service anchors remain available on the service directory.
